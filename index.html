Haru Mail Reader 개인정보처리방침 (Privacy Policy)

시행일: 2026. 10. 25.

1. 앱의 성격

Haru Mail Reader는 운영자 본인(ncdkim@gmail.com)의 Gmail 계정에서 AI 서비스 구독 영수증을 찾아 본인 PC에 보관하기 위한 개인용 도구입니다. 다른 사용자에게 서비스하지 않습니다.

2. 접근하는 정보

Gmail 읽기 전용 권한(https://www.googleapis.com/auth/gmail.readonly)만 사용합니다. 특정 발신자(Anthropic, Google Play, Stripe)가 보낸 영수증 메일의 본문과 PDF 첨부파일만 읽습니다. 메일을 보내거나 수정·삭제하지 않습니다.

3. 저장과 이용

읽은 영수증은 운영자 본인 PC의 폴더와 집계 엑셀 파일에만 저장하며, 영수증 정리와 경비 증빙 외의 목적으로 쓰지 않습니다. 인증 정보는 운영자 PC의 Windows 자격 증명 관리자에만 보관합니다.

4. 제3자 제공

Google 사용자 데이터를 제3자에게 판매·제공·공유하지 않으며, 광고나 AI 모델 학습에 사용하지 않습니다. 이 앱의 Google API 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

5. 권한 철회와 문의

Google 계정 설정의 「서드 파티 앱 및 서비스」에서 언제든지 권한을 철회할 수 있습니다. 문의: ncdkim@gmail.com
